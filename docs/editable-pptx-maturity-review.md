## 发布阻断项

### P1：图片解析存在可达的死循环

`image-size@1.2.1` 命中公开高危公告：

- [ICNS 解析无限循环，GHSA-w3rx-r6r6-pgpr](https://github.com/advisories/GHSA-w3rx-r6r6-pgpr)
- [JXL / HEIF 解析无限循环，GHSA-5p2g-fcmc-qvqq](https://github.com/advisories/GHSA-5p2g-fcmc-qvqq)

`src/lib/svg-pptx-document.ts` 先按声明 MIME 接受 base64 图片，再调用自动识别格式的 `imageSize(data)`，最后才检查实际格式是否允许。因而不受支持的真实格式也可进入存在问题的解析器。

复现使用独立子进程，限制 64 MiB JS 堆和 500 ms 执行时间。一个 16 字节、声明为 PNG 的 ICNS 输入进入 `parseSvg` 后没有返回，被父进程以 `ETIMEDOUT` / `SIGKILL` 终止。没有对正在运行的应用或用户项目执行该输入。

修复要求：使用核验过的修复版本并处理 PptxGenJS 的传递依赖兼容；解析前按签名限制允许格式，增加子进程超时回归。不能直接执行 `npm audit fix --force`，其报告建议降级 PptxGenJS 到 1.1.5，会破坏当前使用的 API。

### P1：百分比坐标的局部降级会丢失整个元素

`src/lib/svg-pptx-document.ts` 的 `rasterElement` 为裁剪 PNG，修改了根 `viewBox`、`width` 和 `height` 后重新渲染。百分比长度会依据新视口重新计算。

复现：1280×720 画布内一个渐变矩形，`x="50%" y="20%" width="20%" height="30%"`。

- 原图有 55,296 个非透明像素。
- 局部边界为 `{x:639,y:143,width:258,height:218}`。
- 实际生成的局部 PNG 非透明像素为 **0**，导出没有因此失败。

修复要求：在保留原画布坐标解析结果的前提下裁剪渲染结果，并为百分比位置、尺寸、嵌套视口增加源图与导出像素对照。

### P1：导出计算阻塞应用主线程

当前 Resvg 渲染、字体扫描、文字测量和局部全画布重渲染都在 Next.js 主线程同步运行。按项目排队与限制 pending 数量无法终止单个耗时任务。

独立审查中，10 个很小的渐变矩形导出约耗时 8–20 秒，10 ms 间隔计时器在期间仅执行 2 次；300 元素探针运行约 3 分钟仍未完成，已停止测试进程。具体耗时受机器负载影响，计时器停顿确认了主线程阻塞。

修复要求：将计算移入有并发限制、超时及可终止能力的 worker/子进程；复用字体加载与文本测量，减少局部降级的重复全画布渲染；设定整份文稿累计像素和降级工作量预算，并验证其它 API 在导出期间仍能响应。

### P1 / P2：其它已复现的静默视觉错误

- 祖先层级的兄弟选择器：`.a + .b rect {fill:blue}`。原图是蓝色矩形，但局部隔离把前兄弟 `.a` 包入 `defs` 后，导出的 `.b` 区域变红。当前只保留直接目标父分组不足以维持选择器的全部结构依赖。
- 闭合后继续绘制的路径：`M10 10 L100 100 Z H200`。`nativePath` 输出终点 `(200,100)`，正确值是 `(200,10)`；`Z` 后没有恢复子路径起点。
- `text-decoration="line-through"` 以原生文本导出且没有降级提示，但删除线丢失。

修复要求：对结构选择器保留完整依赖祖先，无法证明局部等价时采用更大范围的保真降级；纠正路径状态和文本装饰；回归测试必须对照源语义，不能只断言生成包存在对象。

### P1：宿主生产依赖也需要更新

本次 `npm audit --omit=dev` 报告 5 个受影响依赖项：1 个 critical、4 个 high。这是按依赖归并的数量，不代表 5 个独立漏洞。

- `next@15.5.23` 命中 Windows 服务端及 AVIF 图片优化相关严重公告，范围 `<15.5.24`：[GHSA-p293-qw3h-jr36](https://github.com/advisories/GHSA-p293-qw3h-jr36)、[GHSA-2xp9-vwfh-vxw4](https://github.com/advisories/GHSA-2xp9-vwfh-vxw4)。并非每个部署环境都满足对应利用条件，当前 macOS 本地使用不能据此直接判定受攻击。
- `sharp@0.34.5`、Next 内置 `postcss@8.4.31` 也命中高危公告。
- 另外两个受影响项是 `image-size` 和依赖它的 `pptxgenjs`。

修复要求：核验并升级兼容版本及锁文件，从干净环境重新安装、审计和构建，记录无法立即升级的依赖及有效缓解措施。不能仅依赖“本地单用户”作为长期维护方案。
